# Tugas GIT 1

Repository ini berisi tugas pembelajaran **Git, Version Control, dan Markdown**. Tugas ini dibuat untuk memahami konsep dasar version control serta penggunaan Git dalam pengelolaan proyek dan dokumentasi.

## Isi Repository

### 1. Rangkuman Version Control

File `rangkuman1.txt` berisi rangkuman mengenai **Version Control** dan **Version Control System (VCS)**.

Materi yang dibahas meliputi:

* Pengertian version control.
* Perkembangan sistem version control.
* VCS Lokal.
* VCS Terpusat (*Client–Server*).
* VCS Terdistribusi (*Peer-to-Peer*).
* Pengertian dan keunggulan Git sebagai VCS terdistribusi.

### 2. Rangkuman Git

File `rangkuman2.txt` berisi rangkuman mengenai **Git** dan dasar-dasar penggunaannya.

Materi yang dibahas meliputi:

* Pengertian dan fungsi Git.
* Konfigurasi Git.
* Konfigurasi `user.name` dan `user.email`.
* Repository dan cara membuatnya.
* Status file dalam Git.
* Commit dan *staging area*.
* Perintah-perintah dasar Git.
* Branching dan merging.
* Alur kerja Git.

### 3. Rangkuman Markdown

File `rangkuman3.txt` berisi rangkuman mengenai **Markdown** sebagai format penulisan yang banyak digunakan dalam dokumentasi dan pengembangan software.

Materi yang dibahas meliputi:

* Pengertian Markdown.
* Pembuatan dokumen Markdown.
* Heading.
* Format teks seperti tebal, miring, dan dicoret.
* Ordered list dan unordered list.
* Link dan gambar.
* Tabel.
* Source code block.

## Tujuan

Tugas ini bertujuan untuk memahami konsep dasar **Version Control System**, mengenal penggunaan **Git** dalam pengelolaan perubahan proyek, serta mempelajari **Markdown** untuk membuat dokumentasi yang terstruktur.

## Struktur Folder

```text
Tugas GIT 1/
├── rangkuman1.txt
├── rangkuman2.txt
├── rangkuman3.txt
└── README.md
```

## Kesimpulan

Melalui tugas ini, dapat dipahami bahwa **version control** berperan penting dalam mengelola perubahan dan riwayat suatu proyek. Git sebagai VCS terdistribusi menyediakan berbagai fitur untuk mengelola repository, commit, branch, dan kolaborasi. Selain itu, Markdown memudahkan pembuatan dokumentasi yang terstruktur dan mudah dibaca, terutama dalam repository GitHub.
